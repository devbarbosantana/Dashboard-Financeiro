# 💰 Dashboard Financeiro

Aplicação web de controle de gastos pessoais desenvolvida com HTML, CSS e JavaScript puro — sem frameworks, sem dependências além do Chart.js.

> Projeto inspirado em um dashboard financeiro real que automatizei em Excel durante minha experiência como Assistente Administrativo na Ortho Pauher.

---

## ✨ Funcionalidades

- Registro de gastos com descrição, valor e categoria
- Cálculo automático do total gasto
- Gráfico de pizza interativo com distribuição por categoria (Chart.js)
- Interface responsiva e limpa

---

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (ES6+)
- [Chart.js](https://www.chartjs.org/)

---

## 🚀 Como rodar o projeto

1. Clone o repositório:
```bash
git clone https://github.com/devbarbosantana/Dashboard-Financeiro.git
```

2. Abra o arquivo `index.html` no navegador.

Não precisa instalar nada — o projeto roda direto no browser.
